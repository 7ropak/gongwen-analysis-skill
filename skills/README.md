## 与其他目录的分工

- `knowledge-base/` ＝ **判据**（数据、清单、框架）——被技能读取，不主动执行。
- `skills/` ＝ **动作**（步骤、输入输出、Guardrail）——每次执行都会改动上下文或写入文件。
- `prompts/` ＝ **可复用片段**（口径、模板）——被技能与 Agent 引用，避免同一约束在多处重复。
- `schemas/` ＝ **契约**（输入输出字段）——技能对外接口的单一事实源。

## 依赖说明

本项目不依赖其他项目文件；联网检索、信源分级、报告结构等通用口径自持于 `prompts/分析口径片段.md`（片段 C）与 `prompts/输出模板.md`。
