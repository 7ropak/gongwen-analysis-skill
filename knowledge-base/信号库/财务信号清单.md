# 财务信号清单

> **用途**：技能 `财务与合规信号扫描` 的判据来源。用于财报类、披露类公文的「科目—含义」比对与风险扫描。
> **出处**：职业界与案例报道归纳（各条目见 §四）。**性质：实务经验口径，非会计准则或监管规则**——结论须标注为「信号提示」，不写成事实断言。

---

## 一、科目信号 → 含义

| 信号 | 含义（提示级） |
|---|---|
| 应收账款增速长期 > 营收增速，且经营现金流为负 | 可能挂账虚增收入、赊销放宽，坏账风险累积 |
| 利润含金量（经营性现金流净额 ÷ 净利润）长期 ≪ 1 | 利润未转化为现金，或依赖关联交易／存货积压 |
| 商誉 ÷ 净资产 > 30%，且业绩对赌临近到期 | 标的业绩不达预期即触发减值，直接吞利润 |
| 存货激增但预收／营收未同步增长 | 滞销与跌价风险 |
| 有息负债率 > 40%，或资产负债率显著高于同业 | 偿债压力，资金链脆弱 |
| 货币资金「存贷双高」（大额受限资金、货币资金 ≪ 有息负债） | 资金真实性存疑 |
| 在建工程长期不转固、固定资产大额减值 | 虚增资产或资产受损 |
| 「其他应收款／其他应付款」大额关联方往来 | 关联方占款、利益输送嫌疑 |
| 扣非净利润显著差于净利润 | 主业失血，靠卖资产／补贴保利润 |
| 非标审计意见（保留／无法表示／否定） | 审计范围受限、持续经营存疑、内控重大缺陷 |
| 带「持续经营重大不确定性」段落 | 净资产为负、连年亏损、流动负债 > 流动资产、债务逾期 |
| 内控否定意见 | 资金占用、违规担保高发，常伴随风险警示 |
| 控股股东／实控人非经营性占款 | 全链条治理风险，易触发退市指标 |
| 频繁会计政策变更（收入确认、减值计提） | 利润调节手段提示 |

## 二、MD&A（管理层讨论与分析）解读

| 读法 | 判据 |
|---|---|
| **读归因可信度** | 监管要求对营收／营业利润／净利润同比变动说明原因。**把下滑全甩给宏观，而同行同期在增长 ⇒ 归因不可信** |
| **读结构** | 占收入或利润 10% 以上板块须分项列示——据此识别真正的利润来源 |
| **读未来** | 战略、资本支出、风险提示。**风险描述越具体 ⇒ 越坦诚**；通篇「宏观不确定性」⇒ 回避 |
| **读篇幅错配** | 先自行算出哪些指标变动最大，再看 MD&A 是否等比着墨。**小板块大篇幅、大下滑一句带过＝刻意信号**（narrative emphasis analysis） |
| **预警信号集** | 反复出现的一次性调整 · 无量化驱动的模糊措辞 · 与分部利润率／现金流矛盾的乐观叙述 · KPI 或非 GAAP 口径频繁变更 |

## 三、三地信披规则差异（判断文本「本应有什么」）

| 维度 | A 股 | 港股 | 美股 |
|---|---|---|---|
| 定期报告 | 年报＋半年报＋一季报＋三季报（强制） | 主板仅年报＋半年报，季报自愿 | 10-K ＋ 10-Q（3 次） |
| 临时披露 | 事前审核为主，交易所问询、盘后披露 | **事后监管**，股价敏感即时披露 | 事件驱动，8-K 四个营业日内 |
| 重大性 | 量化门槛（金额占净资产比例等） | 原则性判断，强调信息「具体性」 | 「合理投资者」宽口径，SAB 99 明确非单纯 5% 阈值 |
| 停复牌 | 重大资产重组须停牌，一般 ≤10 交易日 | 反对以停牌代替披露 | 无停牌机制 |
| 内幕信息 | 大陆法系量化标准 | 需「具体」才构成内幕消息 | **Reg FD**：选择性披露后须同时或 24h 内公开 |

**问询函机制**：交易所一线监管、事后审核；关注定期报告信披、重大资产重组预案、市场高关注事项；年报问询函聚焦业绩变动、审计意见、毛利率异常。

**业绩预告触发**：净利润为负、扭亏为盈、同比变动 ±50% 以上、净资产为负等；实际与预告差异达 20% 须发更正公告。

**违规类型**：未按期报送／未履行披露义务 · 虚假记载 · 误导性陈述 · 重大遗漏 · 隐瞒关联关系规避披露 · 内幕信息泄露与内幕交易。
