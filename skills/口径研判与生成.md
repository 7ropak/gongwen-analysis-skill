# 口径研判与生成

> 定位：流水线 **S11（发布侧）**——给定一个外部事件，按企业内部研判流程推导「能承诺什么、该发哪种口径、发布前需谁审批」。
> 调用方：`公文分析Agent`（**口径研判模式**）｜ 判据来源：`knowledge-base/公关危机响应流程.md`
> **方向**：本技能是**发布侧**动作（读事件 → 出建议），与其余 7 个技能（读公文 → 出推演）方向相反，共用同一套底层判据。

---

## 输入

| 字段 | 必填 | 说明 |
|---|---|---|
| 事件描述 | ✅ | 发生了什么（可含已发布的唯一口径，若有） |
| 主体 | ✅ | 发布方 |
| 事件类型 | ❌ | 产品安全／召回／数据／财务／人事／其他；缺时由步骤1 判定 |
| 已确认事实 | ❌ | 内部已验证的事实边界（**这是定性充分性的基准**） |
| 上市地 | ❌ | 决定法定披露义务（A股／港股／美股／非上市） |
| 已有口径 | ❌ | 若已发过 Holding Statement，作为续接基准 |

## 输出

| 产物 | 存放位置 |
|---|---|
| 口径研判报告（含四类研判输出 ＋ 承诺边界表 ＋ 口径草案 ＋ 审批提示） | `output/<主体>-口径研判-<YYYYMMDD>.md` |
| 承诺边界表（可承诺／不可承诺／需上报三分） | 报告 §3 |

---

## 执行步骤

### 步骤1：事件分级与牵引人判定
- 判两个维度：**安全敏感度**（是否涉及人身／公共安全或法定披露事项）× **传播速度**（是否已在发酵）。
- 判事件类型（见输入表）；类型非产品安全类时，明确标注哪些内部研判分支不适用。
- 牵引人：素材仅记载「未公开时可能为产品线 BU 或公司级专项组」——本技能**只标注「牵引层级待定，须由主体内部确认」**，不推测具体部门。

### 步骤2：六分支研判清单
逐分支列出「该问什么」，交给用户或对应部门核填（**本技能不代填内部证据**）：

| 分支 | 要回答的问题 |
|---|---|
| 研发／产品工程 | 能否复现？失效模式是什么？设计边界在哪？ |
| 质量／制造／供应链 | 涉及哪些批次／来料／装配环节？过程可追溯吗？ |
| 客服／销售 | 用户咨询、退订、门店反馈的量级与内容？ |
| 投资者关系 | 是否触及法定披露？资本市场压力点在哪？ |
| 法务／合规／监管事务 | 是否构成召回／缺陷／承责义务？证据链完整度？ |
| 品牌／公关 | 舆情焦点、媒体问什么、叙事风险在哪？ |

### 步骤3：四类研判输出
- **事实底座** ← 研发 ＋ 质量分支（＋ S2 的公开信息补充）
- **压力图** ← 客服／销售 ＋ 投资者关系分支；**与 S3／S6 的推演结果并置**（实测反馈 vs 推演，差异处标注）
- **承诺边界** ← 法务分支（见步骤4）
- **公众叙事** ← 品牌／公关分支（用 `声明策略库` §一／§二 选策略）

### 步骤4：承诺边界三分表（本技能的核心产物）
| 类别 | 判据 |
|---|---|
| **可承诺** | 内部已验证且能力可及——写清可核验时点与方式 |
| **不可承诺** | 超出证据范围／超出处置能力／涉第三方——写明理由 |
| **需上报** | 涉及法定披露、召回义务、赔偿口径、责任承认 ——**一律标注「须经法务／合规与高层确认」** |

> 判据：**对外表述不得超出内部已验证的证据范围**。超出者一律移入「不可承诺」或「需上报」。

### 步骤5：定性充分性判定与口径分流
- 事实**不足以**定性 ⇒ **Holding Statement**：只承认真实且已确认的部分，不预判定性。
- 事实**足以**形成阶段口径 ⇒ **正式情况说明**：事实 ＋ 责任表达 ＋ 措施 ＋ 时间表（结构见 `knowledge-base/公文类型库.md` §三③ 六段式）。
- **红线**：属强制法定披露的事项，不得以「正在调查」长期替代披露。

### 步骤6：口径草案
- 按分流结果起草；**逐句标注**所用策略（IRT 编号），并按 SCCT 一致性规则自检（deny 不可与道歉／补偿混用）。
- 附「每一句的事实依据」清单——无依据的句子删除或改为「待确认」。

### 步骤7：审批与越界提示
- 列出须审批项（承诺边界表中的「需上报」项 ＋ 全部法定披露相关表述）。
- 输出「发布前检查表」：法定披露是否满足／事实依据是否齐／策略是否自洽／时间表是否可核验。

---

## Guardrail

- **不生成虚假陈述**：本技能在证据范围内组织口径，不协助编造或淡化已确认的事实。
- **不规避法定披露义务**：强制披露事项必须满足要求。
- **不代填内部证据**：六分支的内部事实由用户／对应部门提供；缺证据的项一律标「待确认」，不推测。
- **不推测未公开机制**：牵引人层级、审批构成等素材未公开的部分，标注「待主体内部确认」。
- **输出定位**：产物是**内部研判辅助**，不是可对外发布的成品稿；对外发布须经主体审批链路。
- **越界约束沿用解读侧**：不输出投资建议／评级；涉诉涉监管附「非法律意见」。

- [ ] 草案是否逐句标注策略并过 SCCT 一致性检查？
- [ ] 是否给出审批项与发布前检查表？
- [ ] 是否未推测素材未公开的机制？
