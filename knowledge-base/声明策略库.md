# 声明策略库

> **用途**：技能 `声明语用标注` 的判据来源。回答「这份文本**在做什么**」——逐句标注修辞策略，再查一致性。
> **适用范围**：**自愿披露类文本**（危机声明、道歉信、内部信、社媒声明、非上市企业公告）。法定公告修辞空间小，标注结论仅作辅助。
> **出处**：Benoit IRT (1995/1997)、Coombs SCCT、Ware & Linkugel (1973)、Hearit、Dirks/Gillespie、Fuoli & Paradis。

---

## 一、Benoit 形象修复理论（IRT） · 5 策略 14 子策略

> **前提判据**：攻击成立需两条件——①**组织被归因负责** ②**行为被公众视为冒犯**。前两类策略打「责任」，第三类打「冒犯性」，末两类表悔意。

| 策略 | # | 子策略 | 文本特征（标注判据） |
|---|---|---|---|
| **否认 Denial** | 1 | 单纯否认 | 「从未」「不存在」「与事实不符」 |
| | 2 | 转移指责 | 「系 XX 方所为」「由第三方原因导致」 |
| **规避责任 Evasion** | 3 | 受挑拨 | 「在持续施压下」「遭恶意做空」 |
| | 4 | 无力控制 | 「不可抗力」「行业性因素」 |
| | 5 | 纯属意外 | 「偶发」「误操作」「疏忽」 |
| | 6 | 动机良善 | 「初衷是好的」「为保障客户利益」 |
| **降低冲击 Reducing offensiveness** | 7 | 寻求支持 | 罗列荣誉、资质、历史贡献 |
| | 8 | 淡化伤害 | 「影响有限」「占比极小」 |
| | 9 | 差异化 | 「行业内普遍做法」 |
| | 10 | 提高层次 | 「为更高价值（就业／安全／国家）考量」 |
| | 11 | 反击对手 | 反诉、追责爆料方 |
| | 12 | 给予补偿 | 赔偿、退款、免费更换 |
| **修正行动 Corrective action** | 13 | 复原＋预防 | 「已修复 X」「将建立 Y 机制」——**须带时间表才成立** |
| **后悔道歉 Mortification** | 14 | 直接道歉 | 「深表歉意」「承担责任」 |

**输出口径**：每句标注 → 汇总各策略出现次数与位置（第几段）→ 得出「该文本的主策略」。

## 二、Coombs SCCT · 10 策略 4 姿态

| 姿态 | 策略 | 适用危机簇 |
|---|---|---|
| **Deny** | attack the accuser／denial／scapegoat | 责任归因可辩 |
| **Diminish** | excuse／justification | 责任低、受伤轻 |
| **Rebuild** | compensation／apology | 责任高、损害重 |
| **Bolster**（辅助） | reminder／ingratiation／victimage | victim 簇专用 |

**危机簇**：victim（受害者，低责任）／accidental（意外，低）／preventable（可预防，高）。

**intensifier（放大器）**：危机史与既往声誉。**Velcro effect**——有负面前史的主体，即使是 victim 类危机也会被读成 preventable。

**一致性规则（硬）**：
- `deny` **不可**与 `diminish`／`rebuild` 混用；
- `diminish` 与 `rebuild` **可以**叠加；
- `victimage` 仅限 victim 簇，误用即被视为推责。

> 一致性违规是「看起来虚伪」的主要机制——**比策略选择本身更值得报警**。

## 三、其他可标注框架

| 框架 | 内容 | 用途 |
|---|---|---|
| **Ware & Linkugel apologia** | denial／bolstering／differentiation／transcendence 四策略 | 早期企业辩解修辞分类 |
| **Hearit 割裂 dissociation** | 三型：意见／知识 · 个体／组织 · 行为／本质（「属个别员工行为，不代表公司」） | 识别「切割」话术 |
| **信任修复** | 言语修复（道歉／否认／解释／承诺／沉默）＋ 行动修复（赔偿、惩罚、penance） | **关键判据**：能力型违规 → 道歉更有效；**诚信型违规 → 否认更有效**（一次不诚信即定性） |
| **合法性修复（Suchman）** | normalizing accounts（否认／辩解／正当化） · restructuring（选择性承认局部缺陷并果断修补） · avoiding panic | 判断修复路线 |
| **印象管理量化** | 正面词频／语气乐观度／可读性与模糊化（obfuscation）／**归因偏差**（好消息内归因、坏消息外归因） | 可量化、可跨文本对比 |

**Fuoli & Paradis 信任修复话语模型**：neutralize-the-negative（认识情态、证据标记）＋ emphasize-the-positive（评价词）。

### 中文语用：克制施压类（框架外）

IRT 的 14 子策略诞生于欧美公关语境，对中文商业语用中「**不撕破脸的施压**」这一类**无对应项**。标注时写「**框架外 · <类别>**」，并到词库取精确定义定强度，**不套编号**。

| 表达 | 语用功能 | 为何 14 子策略不覆盖 | 精确定义查 |
|---|---|---|---|
| 深表失望／深表遗憾／深表不满 | **含蓄施压**——保留关系前提下的公开不满 | 非 #14 道歉（主体无过错） · 非 #11 反击（未指控未点名） · 非 #12 补偿 | `词库/表态程度谱系.md` 第 3＋ 档；`词库/企业声明用词.md` §一 |
| 别有用心／居心不良 | **动机指称** | #10 提高层次指「为更高价值（就业／安全／国家）考量」，与动机归因不同 | `词库/企业声明用词.md` §三 |
| 呼吁…务必确认／敬请… | **规范呼吁** | #7 寻求支持指「罗列荣誉、资质、历史贡献」，非行业规范请求 | `词库/模糊与限定用词.md` §一 |

> **强度判定不看表态词单点**：企业声明的真实强度＝**行动档位**（见 `词库/企业声明用词.md` §四「行动强度阶梯」）。表态档与行动档须分开记。

## 四、标注流程（三步）

1. **定位攻击**：行为是什么 ＋ 谁被归因负责（若无明确攻击对象，标注「无危机锚点」，转常规解读）。
2. **逐句打标**：用 14 子策略表比对；一句可多标。
3. **查一致性与偏差**：比对 SCCT 混用规则；算归因偏差方向；输出「主策略 ＋ 一致性结论 ＋ 可疑处清单」。
