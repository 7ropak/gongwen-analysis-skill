## 二、分级含义与加载建议

| 级 | 含义 | 建议 |
|---|---|---|
| **L1 通识** | 通用语言/常识层面的内容，模型多半已掌握 | **可跳过**：能准确说出即可不读 |
| **L2 专门** | 需要精确条目（分寸差、量化阈值、结构骨架） | **需要时查**，读对应卷而非整库 |
| **L3 专属** | 本项目自建口径或用户私有内容 | **必须查**——模型训练资料中不可能有 |

> **自评句式**：「我能否准确说出这一卷的核心内容（含分寸差与判据）？」能 ⇒ 跳过 L1 部分；不确定 ⇒ 读。

## 三、库的通用约定

1. **一库一 README**：每个子库首件为 `README.md`，写明「包含什么 / 分级 / 怎么查 / 怎么维护」。
2. **条目须附出处**；无权威来源者标注「实务归纳」并说明依据。
3. **只增不减**：过时条目补「时效注」，不删（保留判断沿革）。
4. **口径性质必须标注**：区分「监管规则」「学术框架」「实务归纳」三类，不得混用。
