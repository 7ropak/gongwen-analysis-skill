# 词库

> **本库回答**：公文里的某个词，在这个语境下**到底是什么意思**——尤其是程度、分寸与隐含动作。

## 加载建议（分级）

> **覆盖度**：以 **L1 通识**为主，含 **L2 专门**条目（企业语境的分寸差、隐含动作）。
> **若你已掌握**「关切／遗憾／谴责／抗议」的基本程度序列 ⇒ 可只查 L2 条目与具体卷的语境注；**不确定则整库读**（约 1.2 万字符，三卷）。

| 卷 | 内容 | 级别 |
|---|---|---|
| `表态程度谱系.md` | 表态词从「关切」到「勿谓言之不预」的完整程度阶梯；谈判／会谈用语的隐含分级 | L1（序列）＋ L2（分寸差） |
| `企业声明用词.md` | 企业危机声明中的道歉、遗憾、失望、澄清、追责、法律行动等用词，及**行动强度阶梯** | L2（核心） |
| `模糊与限定用词.md` | 「有关」「个别」「原则上」「将视情况」「正在核实」等模糊表述的实际含义 | L2 |

## 用法

1. **遇到表态词** → 查对应卷，取「含义 ＋ 隐含信号 ＋ 判读提示」。
2. **同一文本多个表态词** → 按程度阶梯取最高一档，判断该文本的**实际立场位置**。
3. **企业声明**优先查 `企业声明用词.md`（外交／党政语境的谱系只作参照，两者分寸不同）。

## 条目格式（新增须遵守）

| 字段 | 说明 |
|---|---|
| 用词 | 原文用词（含常见变体） |
| 程度 | 在阶梯中的位置（数字或相对位置） |
| 含义 | 该语境下的实际意思 |
| 隐含 | 说这话的人下一步可能做什么 |
| 判读提示 | 分析时的注意点（易误读处） |
| 出处 | 可查来源；无来源者标注「实务归纳」 |

## 维护

- **只增不减**：词义随用法变化，旧条目保留并补「时效注」。
- **无出处条目不收录**：除非标注「实务归纳」并说明依据（行业惯例／案例）。
- 新增卷须在本 README 的加载建议表登记（否则视为孤儿）。

### 六条正特征（命中 ≥2 条即「疑似值得入库」）

| # | 特征 | 判据 | 例 |
|---|---|---|---|
| F1 | **承担态度** | 该词在做「表态」而非「陈述事实」 | 深表失望 · 强烈谴责 · 绝无其事 |
| F2 | **程度可分层** | 能与近义词构成强弱序列，换词=换档 | 遗憾 ＜ 深表遗憾 ＜ 谴责 ＜ 抗议 |
| F3 | **行动隐含** | 说了这个词，下一步可能做某事（或不做） | 保留追究权利 ⇒ 可能起诉；正在核实 ⇒ 暂不表态 |
| F4 | **责任/确定性调节** | 缩小范围、留退路、切割责任 | 个别 · 原则上 · 有关 · 系第三方原因 |
| F5 | **公文语域专属** | 日常少用、公文中高频，外行易读错 | 严正声明 · 举一反三 · 保留意见 · 无可奉告 |
| F6 | **有分寸差** | 与近义词存在**不可互换**的差别（最有价值） | 遗憾≠道歉 · 关切＜严重关切 · 澄清≠声明 |

## 维护机制（候选池 · 两种模式）

> 执行体＝技能 `词库维护`。**词库本体只经用户确认后改动**——静默记录写候选池，不写正文。

### 模式一：即时（interactive）

分析过程中遇到「疑似入库」的词 → **当场提出**「可能遇到新的用词：<词>」＋ 出处原文 ＋ 建议卷 ＋ 建议定义 → 询问是否加入。
- 适合：用户在场、单次分析、词的价值明显。
- 用户确认 ⇒ 按卷格式写入正文；用户否决 ⇒ 记入候选池并标「用户已否决」（不再重复询问）。

### 模式二：静默（silent · 默认）

不打断分析，把疑似词记入候选池 `_候选.md`，累积到阈值后**统一判断**。

| 阈值 | 触发 |
|---|---|
| 候选池 ≥ **8 条未决** | 生成审阅表 |
| 跨 ≥ **3 次分析** | 生成审阅表 |
| 用户点名「看看新词」 | 立即生成 |

统一判断的产物＝`debug/词库候选审阅-<日期>.md`：一张表（词 / 出处 / 命中特征 / 建议卷 / 建议定义 / 置信），用户勾选后批量写入；未勾选的保留或丢弃由用户定。

### 候选池格式

见 `_候选.md`（表头已定义）。每条须含：词 · 首次出现文本（含日期） · 上下文原句 · 命中特征 · 建议卷 · 状态（未决／已收录／已否决）。

### 写入正文的规则

1. 按目标卷的条目格式补齐六字段（用词／程度／含义／隐含／判读提示／出处）。
2. **必有出处**：至少给出「出现于哪份文本 ＋ 日期」；能补公开来源更好。
3. 写入后在 `_候选.md` 把状态改为「已收录」，**保留原记录**（可溯源）。
4. **不因新增而改写既有条目**——新词与旧词冲突时，在注释里并列。
