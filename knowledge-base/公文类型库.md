# 公文类型库

> **用途**：技能 `公文类型与结构解析` 的判据来源。定位一份文本「属于什么文种 → 结构应当长什么样 → 缺失哪些组件」。运行时按需读取，不预载。
> **出处**：三路联网调研（沪深交易所公告格式指引、证监会内容与格式准则、党政机关公文处理工作条例、GB/T 9704—2012），条目级出处见文末。

---

## 一、分类主轴（三步定位）

| 步 | 轴 | 取值 | 作用 |
|---|---|---|---|
| 1 | **发布主体** | 上市公司／非上市企业／董事会 · 监事会 · 股东会／主要股东／中介机构／交易所 · 监管 · 司法 | 决定适用哪套格式规则 |
| 2 | **法定性** | 强制法定披露 ＞ 自律规则要求 ＞ 自愿披露 ＞ 无强制 | **决定修辞空间大小**——法定披露可读「结构缺失」，自愿披露可读「修辞选择」 |
| 3 | **时效** | 定期（年报 4 月底／半年报 8 月底）｜触发式临时 | 决定事件是否仍在窗口内 |

> 分类主轴＝**法定性 × 时效**。修辞类分析方法（语用标注）只在「自愿披露」档全面适用。

## 二、类型表

### 上市公司文本（沿用《上市公司公告电子化规范》GA–GG 编码）

| 码 | 大类 | 代表文种 |
|---|---|---|
| GA | 首次披露 | 招股说明书、发行公告、上市公告书 |
| GB | 定期报告 | 年报、半年报、一季报、三季报、业绩预告／快报 |
| GC | 交易类临时 | 重大合同、购买出售资产、对外投资、对外担保、关联交易、重大资产重组 |
| GD | 公司治理类 | 董事会／监事会／股东会决议、独立董事声明 |
| GE | 权益变动类 | 权益变动报告书、收购报告书、质押冻结、增减持、回购 |
| GF | 融资类 | 募集资金用途变更、可转债、股权激励 |
| GG | 其他临时 | 异常波动、澄清公告、重大诉讼仲裁、更名 |

### 其他主体文本

| 类别 | 代表文种 | 强制结构 |
|---|---|---|
| 危机与公关 | 危机声明、道歉信、召回公告 | 无国标，实务六段式 |
| 非上市企业 | 内部信／全员信、官方博客、社媒声明、合同条款变更 | 无 |
| 破产重整 | 法院受理重整／和解／清算公告 | 有（交易所指引） |
| ESG | 可持续发展报告 | 有（双重重要性、21 项议题） |
| 党政机关 | 决议 · 决定 · 命令 · 公报 · 公告 · 通告 · 意见 · 通知 · 通报 · 报告 · 请示 · 批复 · 议案 · 函 · 纪要（15 种） | 有（GB/T 9704） |

## 三、结构模板（四套骨架 ＋ 映射）

### ① 上市公司公告通用骨架
`公告头`（证券代码 · 简称／公告编号／发布主体类别码／标题／公告类别码／发布日期）→ `公告体`：①董事会保证声明 ②重要内容提示 ③分条正文 ④特此公告 ⑤董事会落款＋日期 ⑥备查文件。

### ② 定期报告（年报十章）
重要提示 · 目录 · 释义 → 公司简介与主要财务指标 → **管理层讨论与分析（MD&A）** → 公司治理 → 环境和社会责任 → 重要事项 → 股份变动及股东情况 → 优先股 → 债券 → 财务报告。

### ③ 危机声明六段式
开场确认（20–30 字）→ 事实描述（50–80 字）→ 责任表达／道歉（30–50 字）→ 具体措施含时间表（80–120 字）→ 承诺与防再发机制 → 联系方式与监督窗口。

### ④ 问询回复三段闭环
致函抬头 → 收到函件说明（含文号）→ 逐题：**问题原文摘录 → 公司回复 → 中介机构核查意见** → 落款。

### 其余文种的结构映射

| 文种 | 骨架 | 必备组件 |
|---|---|---|
| 澄清公告 | ① | 传闻简述（媒体 · 时间 · 内容）→ 逐条澄清（涉控制权须引用控股股东回函）→ 风险提示 |
| 召回公告 | 自定义 | 生产者 → 召回编号／时间／数量 → 车型与 VIN 范围 → 缺陷描述 → 可能后果 → 维修措施 → 应急处置 → 通知方式与热线 |
| 董事会决议公告 | ① | 会议召开情况（通知方式／出席人数／主持人）→ 逐项议案＋**同意 · 反对 · 弃权票数**＋关联董事回避 → 备查文件 |
| 破产重整公告 | ① | 法院裁定受理概述 → 指定管理人 → 对上市公司影响（交易／停复牌）→ 风险提示 |
| 业绩预告 | ① | 预计区间 → 变动原因 → 是否经审计 → 风险提示 |

## 四、结构缺失＝异常信号（本库的分析价值点）

| 缺失的组件 | 可能含义 |
|---|---|
| 法定公告缺「重要内容提示」 | 存在应提示未提示的风险项，或被弱化处理 |
| 澄清公告缺控股股东书面回函 | 涉及控制权事项时属披露不完整 |
| 决议公告未列反对／弃权票数 | 掩盖内部分歧 |
| 危机声明缺具体措施与时间表 | 仅表态不承诺，后续兑现压力小、诚意易被质疑 |
| 业绩预告缺变动原因量化 | 归因回避 |
| 年报 MD&A 中变动最大科目篇幅最小 | 叙事篇幅与重要性错配（narrative emphasis） |
