# 潜台词库

> **包含**：公告与声明中常见措辞的**实务读法**——「这句话在市场上通常被理解为什么」。
> **分级**：**L3 专属**（本项目自建、实务归纳；模型训练资料中无可靠对应，须查）。
> **性质警告**：本库条目**来自市场经验与媒体解读，不是监管规则**。使用时必须标注「经验口径」，且不得写成事实指控。

## 内容

| 卷 | 覆盖 |
|---|---|
| `公文潜台词清单.md` | 人事与治理类 · 重大事项与停复牌类 · 风险与安抚类 · 会计与业绩类（约 25 条） |

## 怎么查

1. **先定文种**（S1 结果）：同一措辞在澄清公告与自愿声明中含义不同。
2. 按「措辞关键词」定位条目 → 取「实务读法」。
3. 与文本原文分栏呈现，**不合并成结论句**。
4. 涉具体主体时写成「需核实项 ＋ 核实路径」，不写指控。

## 怎么扩

- **按行业加卷**：`<行业>-潜台词.md`（如地产、医药、金融），条目须带该行业的实际案例出处。
- **按主体类型加卷**：上市公司 / 非上市企业 / 机构。
- 新增卷须回写 `knowledge-base/README.md` 的库清单。

## 维护

- 无出处条目**不收录**；标注「实务归纳」者须给出归纳依据（案例数量／行业惯例）。
- 条目随监管环境变化而失效时，补「时效注」，不删除。
