# 公文潜台词清单

> **用途**：技能 `财务与合规信号扫描` 与 `声明语用标注` 的实务对照表。给出「常见措辞 → 实务读法」的映射。
> **⚠️ 性质声明**：本清单条目**来自市场经验归纳与媒体解读，不是监管规则**。使用时必须标注为「实务经验读法」，**不得写成事实结论或指控**。凡涉及具体主体，一律回到原文与公告全文核对。

---

## 一、人事与治理类

| 措辞 | 实务读法（提示级） |
|---|---|
| 「因个人原因辞职」 | 董监高辞职的常见动因：大股东战略安排（伴随重组／定增）、减持套现（离职半年后可减持比例受限）、业绩压力、公司风险暴露 |
| 辞职后声明「不在公司及控股子公司担任任何职务」 | 彻底切割；在风险警示类标的中多见于风险暴露前的避险动作 |
| 「工作变动」 | 语焉不详的兜底表述，市场普遍视为披露不完整 |
| 高管集体辞职 | 常先于重大事项公告发布，或为新股东入主让路 |
| 董秘职位长期空缺或频繁更换 | 信息披露链条不稳定 |

## 二、重大事项与停复牌类

| 措辞 | 实务读法 |
|---|---|
| 「控股股东筹划重大事项」 | 往往对应控制权变更或资产重组；A 股须停牌并每 5 个交易日披露进展 |
| 「正在核查中」「相关事项尚不确定」 | 交易所已介入或风险未明，须关注后续问询函回复 |
| 「为避免股价异常波动」 | 常出现在确有未披露事项的场景 |
| 「本次交易尚需取得相关部门批准」 | 交易存在实质不确定性，留意审批节点 |
| 「终止筹划」 | 复盘此前停牌期间是否有减持、质押动作 |

## 三、风险与安抚类

| 措辞 | 实务读法 |
|---|---|
| 「对公司经营无重大影响」 | 标准安抚话术——**须自行核对金额、占净资产比例与后续追责** |
| 「不存在应披露而未披露的信息」 | 澄清公告惯用语，须核对是否逐条回应传闻 |
| 「保留追究法律责任的权利」 | 多见于反击型声明，实际起诉比例通常低于表述强度 |
| 「已委托律师处理」 | 同上；关注是否真的进入诉讼程序 |
| 「生产经营正常」 | 与银行账户冻结、供应商断供等信息交叉验证 |
| 「将视情况决定是否……」 | 承诺强度弱化，兑现压力小 |

## 四、会计与业绩类

| 措辞 | 实务读法 |
|---|---|
| 「受宏观经济及行业周期影响」 | 通用外因归因；对照同业同期表现判断可信度 |
| 「一次性因素」反复出现 | 需核对该「一次性」是否已成常态 |
| 「基于谨慎性原则计提」 | 大额减值前兆或业绩洗澡信号 |
| 「调整会计估计」 | 关注调增还是调减利润方向 |
| 「同比口径不可比」 | 核对是否存在并购、剥离或合并范围变化 |
| 业绩预告「上限与下限区间极大」 | 内部对结果不确定，或为后续修正留空间 |

---

## 五、使用纪律

1. **一律标注为经验读法**，与文本原文分栏呈现，不合并成结论句。
2. **不作为指控依据**——潜在含义 ≠ 事实；涉及违法嫌疑的表述只写「需核实项」，写清核实路径（如查问询函、查后续公告）。
3. **交叉验证优先**：同一措辞在不同文种中含义不同（如澄清公告 vs 自愿声明），先定文种再套表。
4. **清单是开放的**：新增条目须附出处（媒体／案例链接），无出处的猜测不入表。
