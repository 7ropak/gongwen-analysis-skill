# 信号库

> **包含**：财报与信息披露文本的**信号—含义对照**、MD&A 读法、三地规则差异。
> **分级**：**L2 专门**（通识部分可跳过，量化阈值与规则差异须查）。
> **用途**：避免每次分析都重新联网检索同一批对照表。

## 内容

| 卷 | 覆盖 |
|---|---|
| `财务信号清单.md` | 科目信号 → 含义（14 条） · MD&A 五读法 · A股/港股/美股信披差异 · 违规类型 |

## 怎么查

1. **先判适用**：仅财报、定期报告、交易类／权益变动类披露适用。
2. 按「科目名／指标」定位条目 → 取「含义（提示级）」。
3. **阈值一律标注「经验口径」**——阈值无统一权威来源。
4. 需要多期验证的条目（如应收增速 vs 营收增速）在报告中标「需两期以上」。

## 分级说明

- **可跳过**：三大报表的基本结构与勾稽关系（模型通识）。
- **须查**：量化阈值、MD&A 判据、三地信披差异细节（易记错）。

## 怎么扩

- **按行业加卷**：`<行业>-信号.md`（银行／地产／医药等各有专属指标）。
- **按准则变化更新**：会计准则或披露规则修订时，补「时效注」而非覆盖旧文。

## 维护

- 所有阈值须标注来源性质（经验口径／准则规定／监管规则）。
- 新增条目附出处链接；无出处者不入库。
