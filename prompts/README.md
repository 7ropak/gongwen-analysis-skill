# prompts/ — 提示词资产（AI-facing）

> 与 `docs/`（给人看）分开：本目录只放**被 Agent／Skill 运行时读取的提示词片段**。
> 与 `skills/` 不重名混用——`skills/` 放完整能力件，本目录放可复用的片段。

## 当前内容

| 文件 | 用途 | 引用者 |
|---|---|---|
| `分析口径片段.md` | 公共口径片段（分层／概率／信源／越界／用户经验优先级） | `事件背景调研` · `利益相关者建模` · `分析报告生成` · `声明语用标注` · `口径研判与生成` |

> **约定**：新增片段须在技能中被显式引用才保留；无引用者的片段移入 `_archive/`。
